## Processing Pipeline

```text
Sukka List
↓
Remove comments / blank lines
↓
Detect + remove Sukka Marker
↓

↓
Analyze rule behavior
↓
domain / ipcidr / classical
↓
Normalize
↓
Deduplicate
↓
Semantic integrity audit
↓

↓
Output
```
